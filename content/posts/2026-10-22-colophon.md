Everything you are looking at, the words, the dates, the search, and the
few thousand points drifting behind this paragraph, comes out of a single
WebAssembly module written in Rust.

## What lives in the binary

- **The content.** Every markdown file under `content/` is compiled *into*
  the module at build time. Once it has loaded there is nothing left to fetch.
- **The router and the templates.** Clicking a link asks the module for the
  next view; it hands back HTML.
- **Search.** Start typing anywhere. There is no search box until you need one.
- **The field.** A particle simulation with springs, damping and a pointer
  that pushes. Each page has a shape: a sphere for home, a stack of sheets
  for writing, a helix for time, a ring for reading.

JavaScript is kept to the edges: it draws the points the module computes
and passes along the pointer, the keyboard and the clock.

## What does not need it

The same Rust code also runs natively at build time and writes every page
out as plain HTML, along with an RSS feed and calendar files. Without
JavaScript, or WebGL, or patience, the site is still all here.

## The ring

While you read, the points gather into a ring around the text. It closes
when you reach the end. That is the only progress bar on the site.
